## 📝 Translation Status

All translations are currently in **Beta** status and are AI-assisted (using DeepL) with community review.

### Translation Quality

- ✅ **Professional terminology**: Technical terms are properly handled
- ✅ **Consistent structure**: All translations follow the same document structure as the English version
- ✅ **Regular updates**: Translations are updated when the English version changes
- ⚠️ **Community review needed**: Native speakers are encouraged to report errors

## 🤝 Contributing to Translations

We welcome contributions to improve translation quality!

### How to Help

1. **Report translation errors**: [Open an issue](https://github.com/paulortiz199928/awesome-c2pa/issues/new?template=translation.md) with the translation template
2. **Suggest improvements**: Submit a pull request with corrections
3. **Add a new language**: See our [Translation Guidelines](../TRANSLATION_QUALITY.md)

### Translation Guidelines

- Maintain the same structure as the English version
- Keep technical terms (C2PA, manifest, assertion) in English with explanations in your language
- Preserve all code blocks, URLs, and technical examples unchanged
- Use professional, formal tone appropriate for technical documentation
